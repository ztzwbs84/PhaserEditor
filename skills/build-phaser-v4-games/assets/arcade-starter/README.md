# __GAME_TITLE_HTML__

A production-oriented Phaser 4.2.1 TypeScript starter generated by the `build-phaser-v4-games` skill.

```bash
npm ci
npm run check
npm run dev
```

`npm run check` runs TypeScript, domain and gate tests, a production build, real gzip budgets, desktop/mobile Chromium E2E, the strict Phaser audit, and API anchors. It refreshes all six reports/screenshots in `.quality/` and removes stale browser/audit/API evidence when a gate fails. Set `PHASER_BROWSER_PATH` if Chrome or Edge is not in a standard location.

The starter keeps game rules in `src/domain`, Scene orchestration in `src/scenes`, shared ownership in `src/services.ts`, semantic browser controls in `src/ui`, and explicit release budgets in `game-quality.json`. Adapt the browser scenario whenever the sample gameplay loop changes.

Player settings and cross-run statistics use the versioned profile in `src/platform/player-profile.ts`. Extend its validator, migrations, tests, and browser reload proof together before adding durable progression fields. Do not store Phaser objects or live physics state.
